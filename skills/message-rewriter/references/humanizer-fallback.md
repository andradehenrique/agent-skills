# Anti-AI-writing checklist (fallback)

Use this only when the `humanizer` skill is not available. Go through the draft once and fix what you find. The goal is for the message to sound like the user on a good day, not like an assistant.

It is based on Wikipedia's "Signs of AI writing" guide, adapted for short messages in any language. The examples are in English. Look for the equivalent pattern in the draft's language.

## Structure

- [ ] **Staged contrast.** "It's not just X, it's Y" / "More than X, Y". Just say Y.
- [ ] **Closing line that repeats the point.** "This will make all the difference." Cut it.
- [ ] **Announcing opener.** "I wanted to raise an important point:", "It's worth highlighting that". Start with the point.
- [ ] **Forced triad.** Three adjectives or three items when only one or two matter.
- [ ] **Reply that re-explains what the reader knows.** In a thread, the person read what came before, so get to the answer.

## Punctuation and formatting

- [ ] **Too many em dashes (—).** Use a comma, period or parentheses instead. On Slack they are almost never needed.
- [ ] **Bold everywhere.** Use at most one highlight per message, and only for a deadline or an action.
- [ ] **A list where a sentence fits.** Two items become a sentence joined with "and".
- [ ] **Decorative emoji** (🚀✨💡) the user did not use. Keep only the ones from the draft.
- [ ] **Bold labels** ("**Context:** ... **Ask:** ...") in a short message.

## Vocabulary

- [ ] **Inflated words**: "crucial", "fundamental", "robust", "leverage", "empower", "journey", "seamless", "optimize" without a number, "ensure" for everything.
- [ ] **Stacked hedges**: "perhaps we could possibly consider". One hedge is enough.
- [ ] **Support-desk enthusiasm**: "Great question!", "Happy to help", "I hope this helps!".
- [ ] **Formality the user does not have.** If the user writes casually, with contractions or slang, keep that register.

## Final test

Read it out loud. If a sentence sounds like a corporate email or a LinkedIn post, rewrite it the way you would say it to the person next to you.
